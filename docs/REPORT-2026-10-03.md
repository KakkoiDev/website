## Items in this repo

### 1. "Add to contacts" (vCard)
- **What:** a button in the Contact section of `/` and `/ja` that downloads a
  vCard, so someone who scans the 名刺 saves Cyril's details in one tap.
- **Decisions:** static file `public/cyril-antoni.vcf` (vCard 3.0):
  `FN:Cyril Antoni`, `N:Antoni;Cyril`, phonetic names アントニ / キリル
  (`X-PHONETIC-LAST-NAME`, `X-PHONETIC-FIRST-NAME`), `EMAIL:contact@kakkoi.dev`,
  `URL:https://kakkoi.dev`, `TITLE:Software engineer`. **No phone number.**
  Button text in `data/dictionary.ts`: "Add to contacts" / 「連絡先に追加」.
- **Check:** the file parses, the button is ≥44px, both languages.

### 2. Digital 名刺 at `/card`
- **What:** a full-screen QR code to show on a phone when there is no paper
  card, plus the name in both orders and the "Add to contacts" button.
- **Decisions:** one bilingual page (both scripts on one screen, like the 404),
  `noindex`, not in the sitemap, not linked from home. The QR is generated at
  build time as inline SVG (no client JavaScript) and points to
  `https://kakkoi.dev/ja/?ref=phone`.
- **Check:** the QR decodes to that URL; fits a 390px screen without scrolling.

### 3. `/links` that updates itself
- **What:** any public KakkoiDev or KakkoiSchool repo with the GitHub topic
  `kakkoi-links` appears on `/links` automatically.
- **Decisions:** `data/links.ts` stays the curated source of order and wording,
  and curated entries win. Tagged repos not already listed are added to a
  "More projects" group, linking the repo's **Website** field when set, else the
  repo. The build reads the GitHub API (with `GITHUB_TOKEN` in Actions); if the
  API fails, the page falls back to the curated list. The Pages workflow gains a
  weekly scheduled build.
- **Owner step:** tag repos with `kakkoi-links` and fill their Website field.

### 4. `/now`
- **What:** what Cyril is working on this month.
- **Decisions:** English only, like `/links`. A short hand-written paragraph in
  `data/now.ts` (no banned copy: no "full-stack", no living in Japan, no ProOne,
  no client names, no phone), plus a "Recently updated" list built from public
  KakkoiDev repos pushed in the last 30 days (non-fork, non-archived, with a
  description, at most 8). Student repos in KakkoiSchool are not listed.
- **Owner step:** edit `data/now.ts` when the focus changes.

### 5. Share images
- **What:** a designed 1200×630 preview for LinkedIn, Slack, LINE, etc.
- **Decisions:** `public/og.png` (English) and `public/og-ja.png` (Japanese):
  black on white, the name, the title, a faint cube, rendered with the site's
  own fonts by `scripts/og-image.mjs` (Playwright) and committed.
  `twitter:card` becomes `summary_large_image`.

### 6. QR scan tracking
- **What:** know whether the 名刺 QR gets scanned.
- **Decisions:** the card's QR changes from `https://kakkoi.dev/ja` to
  `https://kakkoi.dev/ja/?ref=card`. The print files in `docs/business-card/`
  are regenerated and the QR is decoded to verify it. Analytics: GoatCounter
  (no cookies), counted by a small self-hosted script, **switched off until a
  GoatCounter code is set** in `data/analytics.ts`; the CSP opens only that
  one origin, and only when enabled.
- **Owner steps:** create a free GoatCounter site and put its code in
  `data/analytics.ts`. If the cards are already printed, the old QR keeps
  working; only new prints carry `?ref=card`.

### 9. Japanese learning hub at `/nihongo`
- **What:** one page that gathers Echo, Minihongo, The Roots of Japanese, the
  Anki decks and JP Core, with a short intro. English only (the audience is
  English speakers learning Japanese). Can move to `nihongo.kakkoi.dev` later.
